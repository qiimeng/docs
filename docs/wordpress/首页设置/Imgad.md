# 图片广告模块
作者：[阿城](https://www.hidesg.ink/)

### 广告图片
![](image/Imgad/Imgad-20260901102416.png)
推荐使用横版图片，例如 750 × 360px；支持 JPG、PNG、WebP、GIF。

### 跳转链接
![](image/Imgad/imgad-20260901102451.png)
可填写站内或站外完整链接；留空时图片不可点击。

### 图片说明
![](image/Imgad/imgad-20260901102458.png)
用于无障碍访问；留空时优先使用媒体库中的替代文本。

### 新窗口打开
![](image/Imgad/imgad-20260901102511.png)
在保留当前浏览页面的同时，用一个全新的、独立的浏览器窗口来加载并显示目标链接或页面。
